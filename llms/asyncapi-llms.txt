# AsyncAPI

> AsyncAPI is a Linux Foundation project that publishes the open specification for describing event-driven and asynchronous APIs, plus the toolchain around it: a parser, generator, converter, bundler, diff engine, models generator, a CLI and a browser Studio. It also operates one callable HTTP API — the AsyncAPI Server API at https://api.asyncapi.com/v1 — which exposes the toolchain over HTTP, free and without an API key.

Generated by API Evangelist on 2026-09-06 from https://github.com/api-evangelist/asyncapi.
The provider does not publish an llms.txt of its own (https://www.asyncapi.com/llms.txt returned 404 on 2026-09-06).

## What is callable

The AsyncAPI Server API is the only HTTP API the Initiative operates. It is stateless: every operation takes an AsyncAPI (or OpenAPI) document in the request body and returns a derived document, diagnostics or metadata. Nothing is stored. No authentication, no signup, no keys, no published rate limits.

- Base URL: https://api.asyncapi.com/v1
- OpenAPI 3.1.0: https://api.asyncapi.com/v1/docs/openapi.yaml
- Interactive reference: https://api.asyncapi.com/v1/docs
- Self-host the same service: `docker run -it -p 80:80 asyncapi/server-api` or `asyncapi start api`

Operations:
- POST /validate (validate) — validate a document; returns status, diagnostics and a score
- POST /parse (parse) — parse and resolve a document
- POST /convert (convert) — AsyncAPI 2.x to 3.x, or OpenAPI 3.0 to AsyncAPI
- POST /generate (generate) — run a generator template over a document
- POST /bundle (bundle) — merge documents and their references into one
- POST /diff (diff) — difference two documents
- GET /help (help) — list the commands the server exposes
- GET /version (getVersion) — CLI version, runtime and API health
